How this stays in sync

Entry → Sheet → every device

Every time you tap Add & sync entry, it's sent straight to your Google Sheet — from laptop or mobile, doesn't matter which. If you're offline, it's held here as pending and retried next time you hit refresh or add another entry.

The Ledger and Dashboard tabs always read the full history straight back from the Sheet — that's the single source of truth, not any one browser. So whatever device you check from, you'll see the same complete picture.

First time here? Go to the Settings tab and paste in your Apps Script Web App URL.

One-time setup

Google Apps Script backend (paste this in once)

1. Create a Google Sheet. 2. Extensions → Apps Script. 3. Paste the code below (replaces any previous version — this one adds reading, not just writing). 4. Deploy → New deployment → Web app → Execute as "Me" → Who has access "Anyone". 5. Copy the Web App URL into the field above.

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Entries')
              || SpreadsheetApp.getActiveSpreadsheet().insertSheet('Entries');
  var rows = JSON.parse(e.postData.contents);
  rows.forEach(function(r) {
    sheet.appendRow([r.date, r.amount, r.category, r.paymethod, r.note]);
  });
  return ContentService.createTextOutput(JSON.stringify({status:'ok'}))
         .setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Entries');
  var rows = [];
  if (sheet) {
    var data = sheet.getDataRange().getValues();
    rows = data.map(function(r) {
      return { date: r[0], amount: r[1], category: r[2], paymethod: r[3], note: r[4] };
    }).filter(function(r){ return r.date; });
  }
  var json = JSON.stringify(rows);
  if (e.parameter.callback) {
    return ContentService.createTextOutput(e.parameter.callback + '(' + json + ')')
           .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(json).setMimeType(ContentService.MimeType.JSON);
}
Note: reading data back uses a technique called JSONP (a script-tag fetch) rather than a normal request — this is because Google's Web App doesn't send the browser permission headers a regular fetch needs to read a response from a different site. JSONP works around that reliably; you don't need to do anything differently, it's handled automatically.
